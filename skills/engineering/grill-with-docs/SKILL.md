name: grill-with-docs
description: A relentless interview to sharpen a plan or design, which also creates docs (ADR's and glossary) as we go.
---

Use $grilling, then $domain-modeling.

When given a working plan or design document, including one from $discuss-with-docs, read it first. Use its agreed decisions as the starting point and focus the interview on gaps, contradictions, edge cases, and unsupported assumptions. Reopen an agreed decision when new evidence or a conflict warrants it, explaining why.

Write newly agreed answers and their consequences back into that same document during the interview, alongside the glossary and ADR updates governed by $domain-modeling. Keep proposals and unresolved questions distinct from agreed decisions. Before closing, reconcile the document with the final answers and obtain the user's confirmation of shared understanding as $grilling requires. Pass the document forward as context when the user requests $to-spec.
